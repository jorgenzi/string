# string

Задача командного проекта была в реализации аналога стандартной библиотеки строк на C

Технологии: C, Makefile, Google Test, система модульных тестов

Мой вклад: реализовала 5 ключевых функций из 15 (strlen, strcpy, strcat, strcmp, strstr)

Разработала полноценный модуль sprintf: форматированный вывод с поддержкой основных спецификаторов (%d, %s, %c, %f)

Навыки и достижения:

- Глубоко изучила внутреннее устройство строк в C и механизмы работы с памятью

- Освоила принципы модульного тестирования и отладки низкоуровневого кода

- Научилась работать в команде по Git Flow: code review, разрешение конфликтов, ведение проекта

- Поняла важность написания чистого и поддерживаемого кода на уровне системных библиотек
