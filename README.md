## 🎯 О проекте

`libstring` — это учебно-практический проект по реализации аналога стандартной библиотеки `<string.h>` на языке **C**. 

**Цели проекта:**
- 🔹 Глубокое понимание работы со строками и памятью в C
- 🔹 Освоение принципов написания надёжного системного кода
- 🔹 Практика модульного тестирования низкоуровневых функций
- 🔹 Отработка командной разработки по Git Flow

> 💡 Проект демонстрирует, как работают «под капотом» привычные функции вроде `strlen`, `strcpy` и `sprintf`, и как обеспечить их корректность через тесты.

## ✨ Особенности

### 🔹 Реализованные функции (мой вклад)

| Функция | Описание | Статус |
|---------|----------|--------|
| `s21_strlen` | Возвращает длину строки без учёта `\0` | ✅ |
| `s21_strcpy` | Копирует строку `src` в `dest` | ✅ |
| `s21_strcat` | Конкатенирует строку `src` к `dest` | ✅ |
| `s21_strcmp` | Посимвольное сравнение двух строк | ✅ |
| `s21_strstr` | Поиск подстроки в строке | ✅ |

### 🔹 Модуль `sprintf` — форматированный вывод

Полноценная реализация `s21_sprintf` с поддержкой спецификаторов:

| Спецификатор | Описание | Пример |
|--------------|----------|--------|
| `%d` / `%i` | Целое число со знаком | `42`, `-17` |
| `%s` | Строка символов | `"hello"` |
| `%c` | Одиночный символ | `'A'` |
| `%f` | Число с плавающей точкой | `3.14159` |
| `%%` | Символ процента | `%` |

```c
// Пример использования
char buffer[100];
s21_sprintf(buffer, "User: %s, Age: %d, Rate: %.2f", "Alice", 25, 4.75);
// Результат: "User: Alice, Age: 25, Rate: 4.75"

🔹 Дополнительные преимущества
- ✅ Безопасность: проверки на NULL, переполнение буфера
- ✅ Читаемость: чистый код с комментариями и единым стилем
- ✅ Тестируемость: 100% покрытие модульными тестами через Google Test
- ✅ Портативность: компилируется на Linux, macOS, Windows (MinGW)
